# CyberLab Tracker Frontend

React + Vite + TypeScript frontend for the CyberLab Tracker backend.

## Run

```bash
npm install
npm run dev
```

Local app:

- http://localhost:5173

API base URL:

- http://localhost:8000/api/v1
